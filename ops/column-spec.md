# ネコキチ猫吉 コラム執筆ルール

サイト:ネコキチ猫吉(猫種を問わず、猫好き全体に向けた猫の百科。全猫種・猫の習性を事実中心で網羅する)。
役割分担(横田さん 2026-09-28):週刊ラグドール=ネタ系(ウワサ検証の週刊誌ノリ)、アメショの森=飼育情報系、ネコキチ猫吉=圧倒的情報量。ウワサ検証の型はラグドールに任せ、ネコキチでは使わない。
編集長は猫吉(キジトラ白のオス猫、という設定)。書き手は「ネコキチ編集部」。

## ファイル
- `src/content/columns/<slug>.md`(slug は指示された一覧のとおり。勝手に変えない)
- frontmatter(YAML)は必ずこの形:

```yaml
---
title: "猫が液体みたいに見えるのはなぜ?体のしくみ"   # 32字前後まで。検索される言葉を前半に。【検証】は付けない
description: "……"                      # 80〜120字。記事の結論がわかる文
pubDate: 2026-09-27
category: shuusei                       # shuusei(猫の習性事典) / jitsuyo(暮らし・健康の実用)
tags: ["体", "寝相"]                     # 2〜4個
verdict:
  type: kotai                           # 色分け用:hontou / uso / usoyori / kotai / kochou / warito(習性事典では答えの種類の目安)
  label: "答え:体のしくみと暑さ対策"       # 画面に出る答え。習性事典は「答え:〜」、実用記事は「結論:〜」。「判定:」は使わない
  summary: "……"                          # 1〜2文の結論
art: { coat: brown, pattern: kiji, eye: gold, ears: normal, hair: short, expr: wow }
sources:
  - { title: "……", url: "https://……" }
draft: false
---
```

- `art` は記事の顔イラスト。記事の内容に合う猫にする(三毛の話なら calico、黒猫なら black+solid など)
  - coat: black / white / blue(グレー) / silver / brown / red(茶トラ) / cream / seal / chocolate / lilac / ruddy / cinnamon / fawn
  - pattern: solid(単色) / tabby(しま) / classic(渦巻き) / spotted(斑点) / ticked(ティックド) / bicolor(白との2色) / point(ポイントカラー) / calico(三毛) / tuxedo(ハチワレ白黒) / kiji(キジトラ)
  - eye: gold / copper / green / blue / hazel / aqua / odd(オッドアイ)
  - ears: normal / fold(折れ耳) / curl(カール) / big(大きい) / tufted(先に飾り毛)
  - hair: short / semi / long / hairless / rex
  - expr: normal / smug(ドヤ顔) / wow(びっくり) / sleepy(寝てる)

## 本文の型(猫の習性事典 shuusei)
1. 冒頭2〜3文:定義と答え。その行動・体の特徴が何か、なぜ起きるかを先に書く(前置きの寸劇は書かない)
2. `## 基本データ` 表(項目|内容)。どの猫にも共通する事実を短く
3. `## しくみ` `###` の小見出しで2〜4個。理由・体のつくり。有力な説と仮説を分ける
4. `## 研究とデータ` 研究の年・機関・規模・結果。数字は出典どおり、幅を持たせて「目安」
5. `## 猫種・年齢・性別による違い` 出典があることだけ。わかっていない場合は「はっきりしていない」と書く
6. `## よくある誤解` 俗説は短く、事実で答える(ウワサの紹介を主役にしない)
7. `## 飼い主向けメモ` 箇条書き3〜5個
8. `## 関連項目` サイト内の関連記事・ツール・図鑑へのリンク
- 週刊誌ノリ(【検証】・判定・ドッキリ調の寸劇・オチ)は使わない(週刊ラグドールの役目)。やわらかい口調はOK

実用(jitsuyo)は `## 結論` → `## くわしく`(### 小見出し) → 目安の表 → `## 病院に相談する目安` の順。ノリは控えめに、でも堅すぎない。

- 長さ:本文 2,000〜3,500字
- 表を1つ入れられるなら入れる(Markdownの表)
- サイト内リンクは、指示された slug 一覧にある記事だけ `<a href="/columns/<slug>/">…</a>` で張る。ツールは `<a href="/tools/age/">猫の年齢換算</a>` `<a href="/tools/bcs/">体型チェック</a>` `<a href="/tools/food/">ごはんの量計算</a>` `<a href="/tools/seimei/">猫の姓名判断</a>` `<a href="/tools/match/">猫種診断</a>`、猫種図鑑は `<a href="/breeds/">猫種図鑑</a>` が使える
- 太字は `<strong>…</strong>` を使う(日本語のカッコや句読点と ** が隣り合うと太字にならないため)

## トーン
- 文体は、だ・である寄りのやわらかい口調。事典として事実を先に、短く。例:「5kgのお米より重いこともある。」
- 週刊誌ノリ・アホっぽい寸劇は使わない(2026-09-28 から。ネタは週刊ラグドールへ)。親しみのある一言はあってよい
- 猫への愛は全開。でも一匹・一種だけを持ち上げない。**「猫好きは、結局ぜんぶの猫が好き」**がサイトの芯。各記事に1か所くらい、自然な一言として入れてよい
- 他の猫種や雑種を下げない。猫や飼い主をバカにしない(愛のあるツッコミ)
- 明らかな俗説(猫は痛みを感じない、黒猫は不吉、など)は根拠がなければ「根拠はない」とはっきり書く
- 交ぜ書きをしない(×好奇心おう盛 → ○好奇心旺盛)

## 情報の正確さ(最重要)
- 事実として書くのは確かなことだけ。獣医師監修の記事、学術論文、公的機関(環境省など)、猫の登録団体(CFA/TICA/FIFe)を優先して調べる
- 性格は「よく言われる」と「実際は個体差」を分ける
- 数字(体重・費用・温度・回数・確率)は幅を持たせて「目安」と書く
- 診断・薬・治療法を断定しない。健康の話には受診の目安を書く。緊急性が高いものは冒頭に `<div class="notice">…</div>` で受診を促す
- 自信のない事実は書かない
- 出典は `sources` に 3〜7件(実際に開いて内容を確認したURLだけ)
- 姉妹サイトで深く扱っている話題(アメショの森の症状記事など)は、ネコキチでは要点の一覧にして、控えめにリンクで案内する
- 他サイトの文章をコピーしない。要約・言い換えのみ。引用は1か所15字以内まで
- バズった飼い猫の話は、ニュース記事へのリンクで紹介する(写真の転載・個人アカウント名の記載はしない)
- お迎え(購入)を前面に押す書き方はしない(ペットショップっぽく見えるため)。保護猫・譲渡の選択肢にも自然に触れてよい

## 猫と文化(bunka。2026-10-03 追加)
- 歌・映画・絵など。`category: bunka`、verdict の label は「まとめ:〜」
- 歌詞・台詞・原作の文章は一切引用しない(著作権)。あらすじや内容は自分の言葉で短く。結末は書かない
- 曲名・作品名・発表年・収録作・受賞などの事実は出典で確認する。聴く・見る先は公式(アーティスト公式チャンネル、公式サイト、美術館の作品ページ)だけにリンク。非公式アップロードには張らない
- 絵の画像は載せない(所蔵先のページにリンク)

## 猫の旅(tabi。2026-10-03 追加)
- 猫に会える日本と世界の旅先。slug は `tabi-<地名>`、`category: tabi`、verdict の label は「まとめ:〜」
- frontmatter に `trip`(region japan/world・place・lat/lng・mapQuery・access・scene・photo)。記事の頭に「旅のカード」(写真・東京からの地図・Googleマップ)が自動で出る(`src/components/TripCard.astro`、地図は `src/data/trip-map.ts`)
- 写真は Wikimedia Commons の CC0 / CC BY / CC BY-SA / PD だけ。作者・ライセンス・ファイルページを photo に書く。原画像は `.scratch/tabi/`、`node .scratch/tabi-photos.mjs` で `public/tabi/<slug>.webp`(1200×800)にする。写真がなければ photo を省くとイラスト(scene)になる
- 本文:冒頭 → 基本データ表 → 由来・歴史 → 見どころ → 東京からの行き方(表) → 訪ねるときのマナー → 編集部のひとこと → 関連項目
- 船の便数・運休・駅長の交代・エサやりのルールは変わりやすい。公式(自治体・船会社・施設)で確かめ、「2026年10月時点」のように時点を書く
- コーナーのページは `/tabi/`(地図と一覧)。トップの「猫の旅」枠から入る
