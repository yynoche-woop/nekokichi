猫の目の色は、黒目のまわりの色のついた部分・<strong>虹彩(こうさい)</strong>の色だ。この色を決めているのはメラニン色素の量で、多いほど濃い色に、少ないほど青や灰色っぽく見える。どれだけ色素がつくかは遺伝で決まるので、猫種や毛色によって出やすい目の色がある。

| 項目 | 内容 |

| おもな色 | 青・緑・黄色〜金色・オレンジ〜銅色(カッパー)・ヘーゼルなど |
| 子猫の目 | どの子猫も最初は青い(キトンブルー) |
| 本来の色がわかる時期 | 生後2か月ごろが目安。猫種によってはもっと遅い |
| オッドアイ | 左右で色が違う目。片方は青のことが多い |
| 青い目が出やすい猫 | 白い猫・ポイントカラー |

## しくみ

### 子猫の青い目は「まだ色がついていない」状態

生まれたばかりの子猫の虹彩には、メラニン色素がまだほとんどない。そのため、どの子猫も少しにごったような青い目をしている。これが<strong>キトンブルー</strong>だ。成長とともに色素がついていき、生後2か月ごろには黄色系・緑系・青系など、その猫本来の色が見分けられるようになるとされる。

ただし色が落ち着くまでの時間には幅がある。ネコキチの<a href="/breeds/">猫種図鑑</a>でも、<a href="/breeds/egyptian-mau/">エジプシャンマウ</a>は8か月ごろに緑が見えはじめて1歳半ごろに完成、<a href="/breeds/korat/">コラット</a>は緑が定まるまで2〜4年かかる、と紹介している。

### 白い毛の遺伝子は目も青くしやすい

全身が白くなる遺伝子(KIT という遺伝子にある「ドミナントホワイト」)は、色素をつくる細胞が皮膚に行きわたるのをさまたげる。この遺伝子は、青い目や生まれつきの難聴と結びついていることが知られている。白猫に青い目やオッドアイが多いのは、このためと考えられている。

### ポイントカラーの青い目は「体温」が関係する

<a href="/breeds/siamese/">シャム</a>のように、顔・耳・足先・しっぽだけ色が濃いポイントカラーは、色素をつくる酵素(チロシナーゼ)の遺伝子の変異による。この酵素は温度が低い所でだけよくはたらくので、体の先の冷えやすい所だけ色が濃くなる。目は体の内側にあって温度が高いため色素がつきにくく、青いままになると説明されている。

同じ遺伝子の別の型を持つバーミーズ系は、温度の影響がポイントより小さく、目は黄色〜緑寄り。その中間の型(ミンク)の<a href="/breeds/tonkinese/">トンキニーズ</a>は、青と緑の中間のアクア色になる。

### オッドアイ

左右の目の色が違うのがオッドアイ。片方が青で、もう片方がオレンジ・黄色・茶色・緑のどれかになることが多い。成長のなかで片方の目だけ青が残るとオッドアイになることがある。日本では、片方が黄色でもう片方が淡い銀色や青の猫を「金目銀目」と呼んで大切にしてきた。

## 研究とデータ

| 研究 | わかったこと |
|---|---|
| ポイントとバーミーズの遺伝子(2005年) | カリフォルニア大学デービス校が12品種と雑種の200匹以上を調べ、2つの柄がチロシナーゼ遺伝子の別々の変異と結びつくことを示した |
| 白い純血種の子猫の耳(2019年) | イギリスで白い子猫132匹と、同じ腹の色つきの子猫61匹の聴力を検査。難聴は白い子猫だけに見られ、30.3%(両耳15.9%・片耳14.4%) |
| 同じ研究(目の色別) | 難聴の割合は、青い目が2つで50%、1つで44.4%、青い目なしで22.2%。青い目が1つでもある子猫は約3.2倍なりやすかった |
| 白い純血種の猫の耳(2009年) | ドイツで10品種84匹を検査。難聴は20.2%(両耳10.7%・片耳9.5%)で、目の色と関係があった。性別とは関係がなかった |

どれも検査に来た猫を対象にした研究で、数字は目安。調べた集団によって割合は変わる。

## 猫種・年齢・性別による違い

猫種ごとの目の色の例(ネコキチの猫種図鑑より。おもに CFA の品種基準にもとづく):

| 目の色 | 猫種の例 |
|---|---|

| 緑 | <a href="/breeds/russian-blue/">ロシアンブルー</a>・コラット・エジプシャンマウ・<a href="/breeds/oriental/">オリエンタル</a> |
| 金色〜銅色 | <a href="/breeds/chartreux/">シャルトリュー</a>・<a href="/breeds/bombay/">ボンベイ</a>・<a href="/breeds/burmese/">バーミーズ</a> |
| アクア | トンキニーズ(ミンク) |
| いろいろ | <a href="/breeds/turkish-angora/">ターキッシュアンゴラ</a>・<a href="/breeds/ragamuffin/">ラガマフィン</a>(オッドアイも) |

<a href="/breeds/mix/">ミックス(雑種)</a>の目も、金色・緑・青・オッドアイと本当にさまざまだ。

- <strong>年齢</strong>:子猫は青から本来の色へ変わる。大人になってからの急な変化はふつうではない(下の「飼い主向けメモ」へ)
- <strong>性別</strong>:2009年の研究では、難聴と性別に関係はなかった。目の色そのものの性差は、はっきりしていない

## よくある誤解

- <strong>「子猫の青い目は、そのまま青」</strong>:キトンブルーはどの子猫にもある一時的な色。ポイントカラーや白い猫など、大人になっても青い猫もいるが、多くは成長とともに変わる
- <strong>「青い目の白猫は、みんな耳が聞こえない」</strong>:聞こえにくい子の割合は高いが、研究でも青い目が2つの白い子猫の半分ほど。耳が聞こえる白猫もたくさんいる
- <strong>「オッドアイは病気」</strong>:生まれつきのオッドアイの多くは、白い毛の遺伝子などによる体質。ただし大人になってから片方の色が変わった場合は話が別で、目の病気やけがのことがある

## 飼い主向けメモ

- 子猫の目の色は、生後2か月ごろまでは変わっていくもの。あせらず見守ろう
- 大人の猫の目の色が変わった、にごってきた、左右で違ってきた、というときは早めに動物病院へ。緑内障などの病気やけがで色が変わることがある
- 白い猫、とくに青い目の猫は、耳が聞こえにくいことがある。呼んでも反応しない、後ろから近づくとひどく驚く、などが続くときは獣医師に相談を
- 耳が聞こえにくい猫は、床の振動や手で合図すると伝わりやすい。いきなり触らず、視界に入ってから触れる
