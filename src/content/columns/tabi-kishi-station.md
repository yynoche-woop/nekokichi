和歌山県紀の川市の貴志駅は、ローカル線の終点にある小さな駅だ。ここで三毛猫の「たま」が駅長になったのは2007年。猫の駅長は全国で話題になり、廃線の危機にあった路線に多くの人を呼んだ。今もこの駅では、猫が駅長として勤務している。

2026年は、貴志川線が和歌山電鐵になって20年の節目の年でもある。2025年11月に2代目のニタマ駅長が亡くなり、勤務の体制も大きく変わった。この記事では、今の駅長たちの顔ぶれと曜日ごとの勤務、時刻表から組んだ日帰りコース、東京からの費用までをまとめた。

## 歴史・由来

### 廃線の危機からの再出発

国土交通白書(平成20年度)によると、貴志川線はもともと南海電鉄の路線だった。マイカーが増えて利用者が減り、2004年9月には事業廃止の届出が出された。路線を残したいという住民の運動を受けて、新しくできた和歌山電鐵が事業を引き継いだ。自治体が線路の用地を持って会社に無償で貸し、運営も補助するという形で、路線は残ることになった。

貴志駅そのものは1933年8月に和歌山鉄道の駅として開業した古い駅だ。2006年4月1日に和歌山電鐵へ移ったとき、無人駅になった(Wikipedia)。

### 売店の猫が駅長に

白書によると、貴志駅に併設された売店の飼い猫「たま」「ミーコ」「ちび」が駅長や助役に任命され、話題になった。たまの駅長就任は2007年1月5日。白書は、関西大学大学院の宮本勝浩教授らが、たま駅長の就任1年間の経済波及効果を<strong>約11億円</strong>と試算したことも紹介している。

たまは2008年1月にスーパー駅長に昇進し、同じ年の10月には和歌山県から「ナイト(騎士)」の称号を贈られた。2009年3月からは、たまをモチーフにした「たま電車」が走っている。

### 乗車人員の推移

## 猫の駅長たち

和歌山電鐵の公式サイトをもとに、歴代の駅長を整理した(2026年10月時点)。

| 名前 | 生まれ | 今の立場 |
|---|---|---|
| たま | - | 名誉永久駅長・たま大明神 |
| ニタマ | - | 名誉特別駅長・ニタマ駅守大神 |
| よんたま | 2016年4月17日 | マネージャー駅長(貴志駅長) |
| ごたま | 2021年1月28日 | 福招き駅長(伊太祈曽駅長) |
| ろくたま | 2025年5月5日 | 駅長候補生 |

- <strong>たま(初代)</strong>:2007年1月5日に就任。2015年6月22日に亡くなり、名誉永久駅長となった。同じ年の8月10日、ホームに建てられた「たま神社」に「たま大明神」として祀られた
- <strong>ニタマ(2代目)</strong>:2012年1月5日に就任し、長く貴志駅を守った。2025年11月20日に亡くなり、12月13日に貴志駅で神式の社葬が行われた
- <strong>よんたま</strong>:2017年1月に駅長見習い、2018年に伊太祈曽駅長、2019年にスーパー駅長、2024年1月にマネージャー駅長。今は貴志駅の駅長
- <strong>ごたま</strong>:かぎしっぽの三毛猫。2025年1月7日に就任。伊太祈曽駅長で、貴志駅の駅長代行も兼ねる
- <strong>ろくたま</strong>:2026年1月7日に駅長候補生になり、1月14日から駅での仕事を始めた

ネットにはまだ「ニタマ駅長」と書いた記事が多く残っている。出かける前に公式サイトで今の体制を確認しておきたい。

### 曜日別:どの駅に、どの猫がいる?

公式サイトの勤務予定(2026年10月時点)を、駅ごとに並べ直した。勤務は3匹とも10:00〜16:00だ。

| 曜日 | 貴志駅 | 伊太祈曽駅 |
|---|---|---|
| 日 | よんたま | ごたま |
| 月 | よんたま | ろくたま |
| 火 | よんたま | ごたま |
| 水 | ろくたま | ごたま |
| 木 | ろくたま | ごたま |
| 金 | よんたま | ろくたま |
| 土 | よんたま | ごたま |

こうして見ると、予定どおりなら<strong>どの曜日も両方の駅に猫がいる</strong>。よんたまに会いたいなら水・木曜を外し、ごたまなら月・金曜を外す。ただし勤務予定は急に変わることがあり、体調によって臨時で休むこともある。<strong>前日か当日に公式サイトで確認</strong>してから出かけよう。

## 見どころ

- <strong>猫の顔の駅舎</strong>:デザイナーの水戸岡鋭治さんが手がけ、2010年8月4日に完成。伝統工法の檜皮葺きの屋根で、正面から見ると猫の顔に見える
- <strong>駅長室</strong>:駅長は一日じゅうこの部屋の中で過ごす。ふだんは制服・制帽は着けていない
- <strong>たま神社</strong>:ホームにある、初代たまを祀る神社。今はニタマもここから見守っている
- <strong>たまカフェ・たまショップ</strong>:駅舎の中にあり、待合室を兼ねる。猫をイメージした飲み物やジェラート、たまグッズがある
- <strong>記念メダルとスタンプ</strong>:貴志駅には記念メダルの販売機(たま・ニタマ・ごたま)と刻印機、ホームには重ね捺しスタンプがある
- <strong>伊太祈曽駅</strong>:ごたま・ろくたまの勤務駅。ホームや車庫(検査場)は2014年に国の登録有形文化財になった。記念メダル(たま・よんたま・ごたま)もある
- <strong>個性的な電車</strong>:いちご電車、たま電車、うめ星電車、たま電車ミュージアム号などが走る。どの電車がいつ来るかは日によって違い、公式サイトに電車別の時刻表がある
- <strong>年間行事</strong>:4月のたまの誕生日会、6月の命日祭、8月の鎮座祭、2月22日の「猫の日」の催しなど

## モデルコース

### 日帰り:伊太祈曽駅と貴志駅で2匹に会う(土休日の例)

貴志川線の時刻は和歌山電鐵の公式サイト(2026年10月時点)による。東京からの新幹線と特急は、乗り継ぎで約3時間34分(新幹線旅行研究所)。和歌山駅に10時前に着くには、東京を6時台に出る計算になる。

| 時刻 | 行程 |
|---|---|
| 6時台 | 東京からのぞみで新大阪へ。特急くろしおに乗り継ぐ |
| 10:00 | 和歌山駅の9番ホームから貴志川線に乗る |
| 10:20ごろ | 伊太祈曽駅で降りる。ごたまかろくたまに会う |
| 10:50 | 伊太祈曽駅から貴志行きに乗る |
| 11:00ごろ | 貴志駅。駅長室、たま神社、たまカフェ |
| 13:08 | 貴志駅を出る |
| 13:40ごろ | 和歌山駅。くろしおと新幹線で東京へ |

土休日の貴志行きは、和歌山駅を昼間30分おき(毎時0分・30分)に出る。帰りの和歌山行きは、貴志駅を毎時8分・38分に出る。平日は時刻が少しずれるので、乗る日の時刻表を確認しておこう。

このコースだと、運賃は和歌山→伊太祈曽370円、伊太祈曽→貴志370円、貴志→和歌山480円の合計1,220円。<strong>途中で降りるなら1日乗車券(1,200円)のほうが安い</strong>。

### 1泊:三社参りと猫駅長

貴志川線は、沿線にある日前宮(日前神宮・國懸神宮)、竈山神社、伊太祁曽神社の3社を参る「三社参り」の足として生まれたといわれる(和歌山電鐵)。1日目の午後に和歌山に着いたら、1日乗車券で三社を回り、2日目の朝から駅長に会いに行くと、猫の勤務時間(10時〜)にゆっくり間に合う。

## 東京からの行き方と費用

| 区間 | 時間 | 運賃・料金 |
|---|---|---|
| 東京→新大阪 | 約2時間30分 | のぞみ |
| 新大阪→和歌山 | 約1時間 | 特急くろしお |
| 上の2つの合計 | 約3時間34分 | 片道16,460円 |
| 和歌山→貴志 | 約30分 | 480円 |

東京→和歌山の16,460円は、のぞみとくろしおの普通車指定席を乗り継いだ通常期の料金(新幹線旅行研究所)。601km以上なので往復割引が使え、さらに安くなる場合がある。くろしおは全車指定席で、自由席はない。貴志川線の運賃は和歌山電鐵の公式サイトによる(2026年10月時点)。

<strong>往復の費用の目安</strong>:新幹線+くろしおの往復で約32,900円、貴志川線が960円〜1,200円。合わせて<strong>約3万4千円</strong>。

### 貴志川線の乗り方

- 和歌山駅では<strong>9番ホーム</strong>から出る
- 貴志駅は無人駅。降りるときは、車両の前の運賃箱に運賃を入れる(和歌山駅を除く)
- 伊太祈曽駅は有人駅で、9:00〜17:30に1日乗車券や定期券を扱う。乗るときは整理券を取る
- 1日乗車券は和歌山駅9番ホームの窓口で買える(JRの券売機では買えない)。WEBチケットや、RYDE PASS・Kansai MaaSのアプリのデジタル券もある

### 車で行くなら

貴志駅には駐車場がない。伊太祈曽駅前には時間貸しの駐車場(38台、60分200円、最大400円。2026年10月時点の公式サイトの表示)があり、徒歩約3分。ここに停めて電車で貴志に向かう方法が案内されている。

## ベストシーズン・猫に会いやすい時間

- <strong>時間</strong>:駅長の勤務は10:00〜16:00。この時間に行くのが前提だ
- <strong>曜日</strong>:上の勤務表のとおり。会いたい猫の公休日を外す
- <strong>行事の日</strong>:たまの誕生日会(4月)、命日祭(6月)、鎮座祭(8月)、猫の日(2月22日)などは、駅が華やぐ。そのぶん混むと考えておきたい

駅長は寝ていることも多い。起きている時間帯がいつか、という出典は見つからなかった。季節によって会いやすさが変わるかどうかも、出典では確認できない。駅長室は屋内なので、天気に左右されにくいのはありがたい。

## 持ち物

- <strong>小銭</strong>:無人駅では運賃箱に現金で払う。1日乗車券なら見せるだけ
- <strong>1日乗車券の日付を書くペン</strong>:紙の券は利用日を消えないペンで書く決まり
- <strong>フラッシュを切ったカメラ</strong>:駅長室ではフラッシュ禁止
- <strong>時刻表のメモ</strong>:昼間は30分おき。1本逃すと30分待つ

## 訪ねるときのマナー

- 駅長は<strong>一日じゅう駅長室の中</strong>にいて、外には出ない。直接触ることはできない
- 駅長室のガラスをたたかない。寝ていても起こさない
- 撮影するときはフラッシュを使わない
- 体調によって臨時で休むことがある。<strong>勤務予定は直前に公式サイトで確認</strong>
- 駐車場がないので、貴志駅のまわりに路上駐車しない

## よくある質問

### Q. 駅長に会えない日はある?

ある。それぞれに公休日があり(よんたまは水・木、ごたまは月・金、ろくたまは火・土・日)、体調で臨時に休むこともある。ただ、予定どおりなら貴志駅と伊太祈曽駅のどちらにも毎日だれかがいる。

### Q. 駅長をなでたり抱っこしたりできる?

できない。駅長はずっと駅長室の中にいて、ガラス越しに会う形だ。

### Q. 東京から日帰りできる?

できる。東京を6時台に出れば10時ごろに貴志川線に乗れて、2匹の駅長に会ってから夕方の新幹線で帰れる。移動は片道4時間ほどかかるので、余裕があれば1泊がおすすめだ。

### Q. 雨の日でも大丈夫?

駅長室は屋内で、たまカフェも駅舎の中にあるので、雨でも楽しめる。ただ、大雨や強風で電車が遅れたり止まったりすることはどの路線にもある。荒れた天気の日は、出かける前に公式サイトの運行情報を見ておきたい。

### Q. 子ども連れやペット連れは?

子ども連れなら、いちご電車やたま電車に乗るのも楽しい。小児運賃は大人の半額(和歌山→貴志240円)。ペットを連れて乗れるかどうか、駅長室の前に連れて行っていいかは公式サイトでは確認できなかった。猫の駅長を驚かせないためにも、事前に問い合わせておきたい。

### Q. ICカードは使える?

運賃の支払いにICカードが使えるかどうかは、今回見た公式のページでははっきりしなかった。無人駅では運賃箱に現金で払う案内になっているので、小銭を用意しておくと安心だ。1日乗車券ならWEBチケットやアプリのデジタル券もある。

## 合わせて行きたい周辺スポット

- <strong>三社参り</strong>:日前宮(日前宮駅)、竈山神社(竈山駅)、伊太祁曽神社(伊太祈曽駅)。貴志川線の沿線に並ぶ
- <strong>伊太祁曽神社と道の駅 四季の郷公園</strong>:伊太祈曽駅が最寄り。駅のレンタサイクル「たま自転車」で回れる
- <strong>熊野古道</strong>:伊太祈曽駅は、熊野古道やハイキングコースの発着地としても人気だと和歌山電鐵は紹介している
- <strong>古墳めぐり</strong>:日前宮駅から伊太祈曽駅にかけて、車窓から国の特別史跡・岩橋千塚古墳群が見える。甘露寺前駅のまわりにも古墳が点在する

## 編集部のひとこと

一匹の三毛猫が、ローカル線を救った。猫の力を信じたくなる話だ。たまの後を継ぐ駅長たちも、それぞれのペースで、それぞれの顔で働いている。勤務表を見て「今日はろくたまの日か」と考えるのも、この旅の楽しみ方だと思う。
