コトルは、アドリア海の入り江の奥にある城壁の町だ。中世の石畳の旧市街を歩くと、階段の上、教会の前、お土産屋さんの軒先に猫がいる。町じゅうに猫グッズがあふれ、猫が町の顔になっている。

旧市街の中には、猫が描かれた古い本や版画を集めた小さな「猫の博物館」もある。この記事では、猫が多い理由と言い伝え、地元の保護団体の活動、博物館の中身、城壁と近くの島まで回る1日コース、東京からの費用、訪ねるときの注意とよくある質問までをまとめた。

## 歴史・由来

### 船乗りの猫が住み着いた、という言い伝え

昔から世界中の船が出入りする港町で、船乗りたちがネズミよけに猫を船に乗せていた。その猫たちが港に降りて住み着いた、という言い伝えがある。保護団体 Kotor Kitties も、船でやって来た猫が湾沿いの町に住み着き、ネズミを捕って人々を守った、という話を紹介している。言い伝えなので確かめようはないが、町の人たちはこの話ごと猫を大事にしている。

### ヴェネツィアの城壁の町

コトルの歴史は長い。英語版Wikipediaによると、町の名は紀元前168年の記録に出てきて、ローマ時代から人が住んでいた。1420年から1797年まではヴェネツィア共和国の支配下にあり、旧市街の背後の山肌を、長さ約4.5kmの城壁がジグザグに登っている。旧市街の聖トリフォン大聖堂は1166年の建立だ。

1979年に「コトルの自然と文化歴史地域」として世界遺産に登録され、2017年には城壁を含む「ヴェネツィアの防衛施設群」も世界遺産になった。

### 猫は町のシンボルに

英語版Wikipediaは、コトルの猫を「町のシンボル」と紹介している。旧市街には猫グッズの店がいくつもあり、「猫の広場(Trg od mačaka)」と呼ばれる場所もある。住民があちこちに水やごはん、寝床の段ボールを置いて世話をしている。

## 猫の暮らしと保護活動

### 始まりは旅行者の一言

Kotor Kitties のサイトによると、始まりは2018年。アメリカから旅行に来たエイプリル・キングさんが弱った猫に出会い、モンテネグロ全土に継続的な不妊手術の仕組みがないことを知った。地元でお店を営むダニエラさんらと、店の周りの10匹の手術費を出すところから始め、その年の終わりまでに39匹が手術を受けた。

2019年1月には、コトルで初めての「スペイデー(手術の日)」が開かれ、獣医師2人が2日間で57匹を手術した。その後、2019年2月にアメリカの非営利団体、2020年5月にイギリスの慈善団体として認められ、2021年にはモンテネグロで初めての猫の不妊手術専門のNGOになった。

### 手術の数の推移

| 年 | 手術した数 |
|---|---|
| 2018年 | 39匹 |
| 2019年(最初の通年) | 1,435匹 |
| 2020年(コロナ禍) | 1,099匹 |
| 今の受け入れ能力 | 年に約4,500匹 |
| 累計 | 約9,000匹(3団体の合計) |

数字は Kotor Kitties のサイトの表示による。手術費は、メスが36.30ユーロ、オスが24.20ユーロ(付加価値税21%込み)と公開されている。

### 耳の先のカットは「手術済み」の印

手術を受けた猫は、耳の先を少し切って印をつける。団体はこれを、手術済みを示す国際的な目印だと説明している。同じ猫を二度捕まえずにすむし、地域に「この猫は見守られている」と伝える役目もある。手術のあとは、たいてい翌日に元の場所へ戻す。

### 課題もある

団体によると、旧市街は「安全な場所」と思われて、飼えなくなった猫や子猫が捨てられることが多い。英語版Wikipediaも、栄養不足やけんか、猫風邪のような病気で弱った猫を見かけることがある、と書いている。モンテネグロには、けがをした動物を引き取る施設の仕組みが十分ではない、と団体は説明している。

日本の地域猫と同じで、かわいいだけでは続かない。猫好きは、結局ぜんぶの猫が好き。旅先の猫の暮らしを支える人たちがいることも、知っておきたい。

## 見どころ

### 猫の博物館

旧市街の中、古い修道院の食堂だった建物を使った小さな博物館で、2013年に開館した。住所は Trg Gospa od Anđela(天使の聖母広場)。公式サイトによると、16世紀から1970年ごろまでの、猫が描かれた古書や版画、手稿、硬貨やメダル、広告、絵はがき、新聞や雑誌などが並ぶ。イタリア、スペイン、ドイツ・オーストリア、フランスのものが中心だ。DailyArt Magazine によると、もとになったのはある伯爵夫人の寄贈品だという。

入館料は1ユーロで、収益は地元の猫の世話にも使われる。館内には猫が1匹暮らしていて、ショップでは猫のごはんも買える。開館は5〜10月。開館時間は公式サイトでは確認できないので、現地で確かめたい。ハンガリーのブダペストにも姉妹館があり、こちらは入場無料だ。

### 城壁と聖ヨハネ要塞

旧市街の裏から、山の上の聖ヨハネ要塞まで石段が続く。旅行会社 Easy Balkan Transfers のガイドによると、段数は約1,350段、高さ約280m。登りは45〜60分、下りは25〜30分ほど。入口は旧市街の武器広場の近くにあり、5〜9月は朝7時、その前後の月は朝8時に開く。12〜2月は料金所が閉まる。

入場料は、2023年10月の市議会で外国人旅行者は15ユーロと決まった(セルビアのニュースサイト021.rsの報道)。地元住民は無料。料金は変わることがあるので、現地で確かめたい。真夏の昼は日差しが強いので、朝いちばんか夕方がいい。

### 旧市街を歩く

城壁の中は迷路のような路地と小さな広場が続き、どこを歩いても猫に会える可能性がある。聖トリフォン大聖堂のほか、2021年6月にはモンテネグロで初めての公立水族館「アクアリウム・ボカ」もコトルに開館した。

## モデルコース

### 1日コース(城壁+旧市街の猫+ペラスト)

時刻は一例。夏(5〜9月)の場合。

| 時刻 | 行程 |
|---|---|
| 7:00 | 要塞の入口が開く。涼しいうちに登り始める |
| 8:30 | 要塞から下りてくる。旧市街で朝ごはん |
| 9:30 | 旧市街を歩いて猫探し。猫の広場、大聖堂の周り |
| 11:00 | 猫の博物館(5〜10月) |
| 12:00 | 昼ごはん |
| 13:30 | バスかタクシーでペラストへ |
| 14:00 | ボートで「岩礁の聖母」の島へ |
| 16:00 | コトルへ戻る |
| 18:00 | 夕方の旧市街をもう一周 |

### 半日しかないなら

要塞は飛ばして、旧市街の猫探しと博物館に絞るといい。旧市街は小さく、ゆっくり歩いても2〜3時間あれば回れる(編集部の目安)。

### クルーズ船の日に注意

コトルはクルーズ船の寄港地でもある。コトル港の統計では、2000年は116隻・2,680人だった乗客が、2019年には464隻・613,747人に増えた。2020年はコロナ禍で9隻・3,009人まで減り、2022年には434隻・418,174人に戻っている。2023年の報道では、大型船が1日に5隻入って、乗客が1万1千人近くになった日もあった。

船が入る日は、昼の旧市街がとても混む。コトル港の公式サイトに2026年の寄港予定(エクセル・PDF)が出ているので、旅程を決める前に確かめておきたい。

## 東京からの行き方と費用

### 行き方

| 区間 | 目安 |
|---|---|
| 東京→乗り継ぎ地 | イスタンブール経由が主な経路 |
| ティヴァト空港→コトル | 約7km、車で約15分 |
| ポドゴリツァ空港→コトル | 約75km |
| コトル→ペラスト | 湾沿いにバスやタクシーで |

2026年10月時点で、日本からモンテネグロへの直行便はない。モンテネグロにはUberもBoltもなく、タクシーは空港到着口の外の乗り場か、地元の配車アプリ「MonteGO」を使う。ティヴァト空港のほうがコトルにずっと近い。

### 費用の目安(1人)

| 項目 | 目安 |
|---|---|
| 航空券(東京⇔ポドゴリツァ) | 往復平均 約19万円 |
| ティヴァト空港⇔コトル | 予約制の送迎車 1台70ユーロ〜 |
| 要塞・城壁 | 15ユーロ |
| 猫の博物館 | 1ユーロ |

航空券は KAYAK の表示(2026年10月確認、イスタンブール乗り継ぎの往復平均192,944円)。送迎車は Easy Balkan Transfers の料金(セダン1〜3人)。空港のタクシーや配車アプリなら、これより安くすむこともある。どれも時期や予約のタイミングで変わるので、あくまで目安だ。宿代は別にかかる。

<a href="/columns/tabi-istanbul/">イスタンブール</a>で乗り継ぐなら、行き帰りのどちらかで途中降機して、猫の街を2つ回る旅程も考えられる。

## ベストシーズン・猫に会いやすい時間

- <strong>5〜10月</strong>:猫の博物館が開いている。要塞も朝7時から登れる
- <strong>12〜2月</strong>:博物館は閉まり、要塞の料金所も閉まる。人は少ない
- <strong>朝と夕方</strong>:クルーズ船の客が少ない時間帯。真夏の要塞登りも朝か夕方がいい

コトルの猫に会いやすい時間や季節を調べたデータは、出典では確認できない。一般論として、猫は暑い昼間は日陰で寝ていることが多く、朝夕のほうが動いている姿を見やすい。

## 訪ねるときのマナー

- 猫の多くは地域で見守られている猫。<strong>耳の先にカットがある猫は手術済み</strong>の印
- エサをあげるなら、博物館のショップや団体の案内に従う。人の食べ物、魚の骨、牛乳はあげない(牛乳は猫がおなかをこわしやすい。一般論として)
- 夏は観光客が多く、猫も日陰で寝ている。無理に起こさない
- けがや病気の猫を見つけたら、団体は「動物病院へ連れて行き、費用を手伝って」と呼びかけている。ただし旅行者にできる範囲で
- 寄付は Kotor Kitties の公式サイトから受け付けている

## よくある質問

### Q. 旧市街の猫にエサをあげてもいい?

禁止するルールは確認できなかったが、地元では住民や団体が世話をしている。あげるなら猫用のごはんを少しだけにして、食べ残しやゴミは持ち帰る。博物館のショップで猫のごはんを買える。

### Q. 猫の博物館は冬も開いている?

開館は5〜10月だけ。冬に行く人は注意したい。開館時間は公式サイトに書かれていないので、現地で確かめよう。

### Q. 日本から何日あれば行ける?

乗り継ぎで片道約1日かかるので、コトルに丸1日いるなら最低でも4泊はほしい(編集部の目安)。イスタンブールやクロアチアのドゥブロヴニクと組み合わせる旅程も考えられる。

### Q. 子ども連れでも楽しめる?

旧市街は小さく、猫探しをしながら歩ける。ただし要塞は1,350段ほどの石段が続くので、小さな子どもとはむりをしないこと。

### Q. 雨の日は?

旧市街の散歩と猫の博物館は雨でも回れる。要塞の石段は濡れるとすべりやすいので、雨の日は登らないほうが安心だ。

### Q. 保護猫を日本に連れて帰れる?

Kotor Kitties は譲渡の窓口も設けている。ただ、海外から日本へ猫を連れて帰るには、日本の動物検疫のルールを満たす必要があり、準備に時間がかかる。旅行中の思いつきで決めず、団体と農林水産省の動物検疫所に事前に相談したい。

## 編集部のひとこと

港の猫が町の歴史になった、という話は日本の猫島とも少し似ている。海を渡ってきた猫の子孫かもしれないと思うと、黒猫一匹にもロマンがある。その猫たちの暮らしを、旅行者の一言から始まった団体が支えている、というのもいい話だ。
