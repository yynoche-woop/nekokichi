ローマのど真ん中、バスや路面電車が行き交う広場の一段低いところに、古代ローマの神殿跡が広がっている。トッレ・アルジェンティーナ広場だ。その石柱のあいだで、猫たちが日なたぼっこをしている。

## 基本データ

| 項目 | 内容 |
|---|---|
| 場所 | イタリア・ローマ中心部、Via Arenula と Via Florida の角 |
| 猫との関わり | 遺跡の一角にボランティアの猫の保護区(1993年〜) |
| 保護区の時間 | 火〜日 12:00〜16:30(月曜ほか休み)、入場無料 |
| 東京から | 羽田から直行便で約16時間 |
| 遺跡の遊歩道 | 一般7ユーロ(2026年時点の市の案内) |

## どんな場所?

1926年の取り壊し工事のときに、共和政ローマ時代の神殿4つと、元老院の議場だった「ポンペイウスのクリア」の跡が見つかった。ユリウス・カエサルが暗殺された場所として知られる。

遺跡が地面より低いところにあるため、昔から猫が住み着いていた。1993年、2人の女性が猫の世話を始めたのが保護区の始まりで、当初は約90匹の世話からスタートしたという。今は各国から集まったボランティアが、寄付と募金で運営している。シェルターは神殿のひとつ(神殿D)の基壇のところにあり、猫の世話と不妊手術を続けている。公式サイトによると、これまでの不妊手術は累計で6,900匹を超える。

## 見どころ

### 保護区
遺跡のそばにシェルターがあり、ボランティアが世話をする猫たちに会える。見学は無料で、寄付や、遠くから猫を支援する「遠隔里親」の仕組みもある。

### 遺跡の遊歩道
2023年6月から、遺跡の中を歩ける遊歩道が公開された。段差のない通路と昇降機があり、神殿の跡を間近で見られる。入口は Via di San Nicola de' Cesarini で、20分ごとの人数制限がある。

## 東京からの行き方

| 区間 | 目安 |
|---|---|
| 羽田→ローマ(フィウミチーノ) | ITAエアウェイズの直行便で約15時間45分(毎日運航) |
| 空港→テルミニ駅 | 特急レオナルド・エクスプレスで約30分、14ユーロ |
| 市内→広場 | 中心部なので、ほかの観光地から歩いて回れる |

成田からローマへの直行便は、2026年10月時点では見当たらなかった。

## 訪ねるときのマナー

- 保護区は<strong>月曜と、1月6日・3月15日・8月15日が休み</strong>。3月15日はカエサルが暗殺された日にあたる
- 遺跡の遊歩道は、月曜・12月25日・5月1日が休み。毎月第1日曜は無料
- 猫へのエサやりは、ボランティアの世話に任せる
- 寄付箱やショップでの買い物が、猫のごはんと医療費になる

## 編集部のひとこと

2000年以上前の石の上で、今を生きる猫が昼寝をしている。猫好きにとって、これほど時間の感覚がおかしくなる場所はなかなかない。
