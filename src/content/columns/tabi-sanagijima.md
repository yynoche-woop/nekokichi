佐柳島は、香川県の多度津港から船で1時間弱の瀬戸内海の島だ。人口は約50人。それより多い100匹以上の猫が、港や路地でのんびり暮らしている。堤防のすき間を軽々と飛び越える猫の写真がSNSで広まり、「飛び猫の島」として知られるようになった。

島には店も自動販売機もなく、船は1日4便。気軽に寄れる場所ではないぶん、昔ながらの漁村の暮らしと猫の時間がそのまま残っている。この記事では、島の歴史と猫の暮らし、時刻表から組んだ東京からのモデルコース、費用、持ち物、よくある質問までをまとめた。

## 歴史・由来

### 塩飽の「人名の島」

佐柳島は、瀬戸内海の塩飽(しわく)諸島に属する。香川県の瀬戸内海歴史民俗資料館は、この島を塩飽諸島の「人名(にんみょう)の島」として名高い有人島、と紹介している。塩飽の島々は、昔から船乗りの島として知られてきた。

香川県の冊子(2019年)によると、幕末には島民の何人かが咸臨丸の乗組員になり、坂本龍馬の海援隊でも活躍したという。Wikipediaには、海援隊の佐柳高次が「いろは丸」の事故のときの航海長だったこと、咸臨丸で渡米した島民の一人が航海中に亡くなったことが書かれている。

島は1956年に多度津町に編入された。1995年3月には小・中学校が閉校し、その木造校舎が2017年8月、宿と喫茶「ネコノシマホステル」に生まれ変わった(四国電力の広報誌・Wikipedia)。

### 人口の移り変わり

数字を並べると、島の人口は少しずつ減っている。

| 時点 | 人口 | 出典 |
|---|---|---|
| 2015年10月 | 72人 | 国勢調査(香川県の冊子) |
| 2019年 | 約70人 | 四国電力の広報誌 |
| 2021年 | 60人弱 | Wikipedia |
| 2026年 | 約50人 | ネコノシマホステル、サライ.jp |

猫の数はきちんと数えた記録が見当たらない。2019年の取材では約100匹、2026年の記事では100匹以上とされ、どちらも「人より猫が多い島」という点は変わらない。

### 両墓制が残る島

香川県の冊子によると、本浦と長崎の2つの集落それぞれに「両墓制」の墓が残っている。亡くなった人を埋める「埋め墓」と、お参りするための「参り墓」を分けてつくる、古い風習だ。中でも長崎の埋め墓は、1965年に香川県の有形民俗文化財に指定された。

## 猫の暮らしと保護の取り組み

### 有名になったきっかけ

2019年の四国電力の広報誌によると、島の猫が広く知られるようになったのは、有名な動物写真家が島の猫を撮影し、写真集やテレビで紹介したことがきっかけだった。堤防の切れ目をジャンプする猫の写真が特に話題になり、まねをして撮ろうとする人が増えた。Wikipediaには、岩合光昭さんが『世界ネコ歩き』の撮影で訪れたことも書かれている。

### エサのルール

島の宿・ネコノシマホステルは、持ち込むエサを<strong>ドライフードだけ</strong>にするよう求めている。煮干しや液状のおやつはだめで、与えすぎや置きエサも断っている。2019年の香川県の冊子にも「むやみにエサをやらない」「キャットフードの袋や缶は持ち帰る」とある。

猫は島の人たちに見守られて暮らしている。不妊手術の数や、誰がどのくらい世話をしているかといった具体的な数字は、自治体や宿の公式ページでは確認できなかった。

## 見どころ

### 飛び猫の堤防

本浦港の近くに、ところどころ切れ目のある堤防がある。ここを猫が飛び移る姿が「飛び猫」だ。猫は気が向いたときにしか飛ばない。撮るために猫をあおったり、追い立てたりはしないこと。猫のジャンプのしくみは<a href="/columns/jump/">猫のジャンプ力</a>の記事にまとめている。

### 大天狗神社

本浦にある神社で、なくした物を見つけてくれるという言い伝えがある(香川県の冊子)。300段以上の長い石段の上に天狗さまが待っていて、石段の途中からの海の眺めがいい。夏は暑いので、水を持って登りたい。

### 八幡神社と船渡御

1684年建立と伝わる島の産土神。1824年に奉納された北前船の模型は、多度津町の文化財だ。2019年の冊子によると、10月の3連休には、御神輿を乗せた船が大漁旗の漁船を連ねて港から御旅所へ向かう「船渡御」が行われる。開催の有無は年によって変わりうるので、行く前に確かめたい。

### 長崎の埋め墓とくじら岩

北の長崎集落には、県の文化財になっている埋め墓がある。2つの集落は海沿いの一本道でつながっていて、途中にはクジラのような形の「くじら岩」もある。冊子には「満潮時は注意」とあり、町も磯に降りないよう呼びかけている。

### 島の路地

古い家並みが続く集落を歩くと、あちこちで猫に出会う。2026年9月のサライ.jpの記事では、3時間ほどあれば島の主な場所はだいたい回れるとされている。

## モデルコース

船の時刻は、たどつ汽船の2026年8月1日改正の時刻表による。JRの時刻は2026年10月の時刻表データ(Yahoo!路線情報で検索)で確かめた。どちらも変わることがあるので、出発前に公式で確認してほしい。

### 東京から日帰り(島に約2時間20分)

朝いちばんの新幹線でも、多度津港9:02の船には間に合わない。東京から日帰りするなら、午後の便で渡って最終便で戻る形になる。

| 時刻 | 行程 |
|---|---|
| 9:00 | 東京駅からのぞみ135号 |
| 12:35 | 岡山で特急しおかぜ11号に乗り換え |
| 13:22 | 多度津駅。港まで歩いて約16分 |
| 13:57 | 多度津港から船 |
| 14:53 | 佐柳島・本浦港。飛び猫の堤防、大天狗神社 |
| 17:11 | 本浦港から最終便 |
| 18:04 | 多度津港。駅へ歩く |
| 18:59 | 多度津駅から特急南風24号 |
| 20:01 | 岡山でのぞみ60号に乗り換え |
| 23:12 | 東京駅 |

島にいられるのは2時間あまり。長崎集落まで足をのばす時間はあまりないので、本浦のまわりに絞るのが現実的だ。

### 1泊2日(島に約5時間半)

前の日のうちに多度津や丸亀まで行って泊まれば、朝の便で渡れる。

| 時刻 | 行程 |
|---|---|
| 1日目 | 東京から多度津・丸亀へ。こんぴらさんに寄ってもいい |
| 9:02 | 多度津港から船 |
| 9:55 | 本浦港。長崎集落まで歩いて一周 |
| 15:19 | 本浦港から船 |
| 16:12 | 多度津港 |
| 16:59 | 多度津駅から特急南風20号 |
| 21:06 | 東京駅(岡山でのぞみ104号に乗り換え) |

島に泊まりたいなら、ネコノシマホステルを予約する。午後の便で渡って島に泊まり、翌朝の静かな港を歩くのも佐柳島らしい過ごし方だ。

### 長崎港の便に注意

長崎港に寄る便は限られる。2026年8月改正の時刻表では、多度津発6:45(本浦には寄らない)と13:57の2便が長崎に着き、長崎発は7:46と15:06の2便だけ。長崎から乗るつもりなら、時刻を必ず控えておこう。

船は「新なぎさ2」で、車を積んでいるときの定員は95人。たどつ汽船は、<strong>島民優先で、定員に達したら乗船を断る</strong>としている。行楽シーズンは早めに港へ。土曜日だけは、13:57発の便が本浦で岡山県の真鍋島行きの船に接続する。天候で欠航することもあるので、当日の運航状況を確かめたい。

### 費用の目安(大人1人)

| 区間 | 片道 | 往復 |
|---|---|---|
| 東京→多度津(新幹線・特急、自由席) | 18,350円 | 36,700円 |
| 多度津港→本浦(船) | 690円 | 1,380円 |
| 合計 | 19,040円 | 38,080円 |

JRの運賃・料金は2026年10月時点のYahoo!路線情報の表示で、新幹線と特急の自由席を使った場合。指定席だとこれより高くなる。船の運賃はたどつ汽船の公式による。小学生と1歳以上の未就学児は大人の半額で、大人1人につき未就学児1人は無料。

飛行機なら、羽田→高松が約1時間20分。高松空港からはバスとJRを乗り継いで多度津まで1時間半ほどかかる。JALの普通運賃は片道48,540円(Yahoo!路線情報の表示)だが、早割や成田発のLCCを使えば大きく下がる。運賃は時期と予約のタイミングで大きく変わるので、航空会社のサイトで比べてほしい。

車の場合、多度津町港務所の建物の裏に駐車場がある(事前の申請は不要)。たどつ汽船には駐車場がない。車を船に乗せるのは全便予約制。

## ベストシーズン・猫に会いやすい時間

- <strong>春と秋</strong>:日陰も店もない島なので、歩きやすい季節がいちばん。秋は八幡神社の船渡御(10月の3連休、2019年の冊子)に合わせる手もある
- <strong>夏</strong>:暑さが厳しく、飲み物を買える場所がない。台風の時期は欠航にも注意
- <strong>混む時期</strong>:たどつ汽船は、9月の連休まわりに混雑で乗れない人が出るおそれがあると告知していた。連休は早めに港へ

猫に会いやすい時間や季節は、公式の出典では確認できない。一般論として、猫は朝と夕方に活発になることが多い。日帰りだと島にいるのは午後だけになるので、朝の猫を見たいなら前泊か島泊にしよう。

## 持ち物

- <strong>飲み物と食べ物</strong>:島に店も自販機もない。多度津で買ってから乗る
- <strong>ゴミ袋</strong>:ゴミは全部持ち帰る。島で処理する手間をかけない
- <strong>ドライフード(あげるなら少量)</strong>:煮干しや液状のおやつはだめ。袋も持ち帰る
- <strong>帽子・日焼け止め</strong>:日陰が少ない
- <strong>歩きやすい靴</strong>:大天狗神社の石段は300段以上
- <strong>現金</strong>:船の切符は多度津港の乗り場入口で買う
- <strong>帰りの船の時刻のメモ</strong>:乗り遅れると島から出られない

## 訪ねるときのマナー

- 持ち込むエサは<strong>ドライフードだけ</strong>。与えすぎ・置きエサはしない。食べ残しはイノシシやカラスを呼んでしまう
- エサをあげるなら、道路など危ない場所は避け、一度に食べきれる量にする
- 散策は日の出から日没まで。集落の中にはなるべく入らない(多度津町)
- キャンプ・バーベキュー・花火など火の使用は禁止。長崎地区では夜釣りも禁止
- ネコノシマホステルの敷地を使うときは、オーナーに確認する
- 海岸沿いは一周できない。潮が満ちると戻れなくなるので、磯に降りない
- 猫を島から連れ出さない
- 帰りの船に乗り遅れないよう、時刻に十分注意する(多度津町)

## よくある質問

### Q. 猫にエサをあげてもいい?

島の宿は、持ち込むならドライフードだけ、与えすぎや置きエサはしない、とお願いしている。煮干しや液状のおやつはだめ。あげないのがいちばん迷惑をかけない選択でもある。

### Q. 東京から日帰りできる?

できる。東京9:00発の新幹線で13:57の船に乗り、17:11の最終便で戻れば、東京に23時すぎに着く。ただし島にいられるのは2時間あまり。ゆっくり回るなら前泊か島泊がいい。

### Q. 島にトイレはある?

トイレについては、町や船会社の公式ページでは確認できなかった。船に乗る前、多度津港で済ませておくと安心だ。

### Q. 雨の日でも楽しめる?

雨宿りできる店がなく、猫も軒下に隠れてしまう。石段や磯は滑りやすい。天気が悪いと船が欠航することもあるので、雨の予報なら日をずらすのが無難だ。

### Q. 子ども連れやペット連れでも行ける?

子どもは小学生まで船が半額。ただし店がないので、飲み物とおやつは多めに。ペットを船に乗せられるかは公式ページでは確認できなかった。猫が多い島なので、犬を連れていくと猫を驚かせてしまう。

### Q. 何時間あれば回れる?

主な場所は3時間ほどで回れる、とサライ.jpは紹介している。長崎集落まで歩くなら、朝の便で渡って午後の便で戻るのが安心だ。

## 合わせて行きたい周辺スポット

- <strong>高見島</strong>:同じ船で途中に寄る島(多度津から500円)。石垣の集落と両墓制、映画のロケ地になった大聖寺があり、鐘楼門の屋根を力士像が支えている。こちらも店・自販機はない(香川県の冊子)
- <strong>真鍋島(岡山県)</strong>:土曜日だけ、佐柳島の本浦から船がつながる
- <strong>金刀比羅宮(こんぴらさん)</strong>:多度津駅からJRで琴平まで10〜15分。御本宮まで785段の石段がある
- <strong>丸亀</strong>:多度津駅から特急で4分、普通でも6分ほど。前泊の拠点にしやすい

## 編集部のひとこと

猫が堤防を飛ぶのは、猫にとってはただの通勤路だ。人間が勝手に感動しているだけ、というのも猫らしくていい。店も自販機もない島で、人より多い猫がのんびり暮らしている。その静けさを守れるかどうかは、訪ねる側にかかっている。
