猫の毛色と模様は、いくつかの遺伝子の組み合わせで決まる。しま模様が出るかどうか、しまの形、色の濃さ、白い毛の入り方、体の先だけ色が濃くなるかどうかは、それぞれ別の遺伝子が受け持っている。キジトラやハチワレといった日本の呼び名も、ロゼットやミテッドといった猫種の世界の呼び名も、その組み合わせに付いた名前だ。

## 基本データ

| 呼び名 | どんな毛色・模様? |
|---|---|
| キジトラ | 茶色っぽい地に黒いしま。メスのキジの羽に似た色 |
| サバトラ | グレーの地に黒いしま。英語ではシルバー(ブラウン)タビーに近い |
| 茶トラ | 明るい茶色(レッド)の地に濃い茶色のしま |
| ハチワレ・タキシード | 黒と白のブチで、顔の黒が八の字に割れて見える |
| 三毛・サビ | 黒と茶がまざる模様。白が入ると三毛、入らないとサビ(トーティ) |
| マッカレル | 細いしまが縦に並ぶ「サバ」のような模様 |
| クラシック | 太いしまが体の横で渦を巻く模様(ブロッチド) |
| スポッテッド | しまが途切れて斑点になった模様 |
| ティックド | 体にしまがなく、1本の毛が何色にも分かれて見える(アビシニアンなど) |
| ポイント | 耳・顔・足・しっぽだけ色が濃い(シャム、ラグドールなど) |
| ミテッド・グローブ | ポイントに白い足先(ラグドールのミテッド、バーマンの白い手袋) |
| セピア・ミンク | ポイントより色の差がゆるやか(バーミーズ、トンキニーズ) |
| ロゼット・マーブル | 中が明るく抜けたヒョウのような斑点、大理石のような模様(ベンガル) |
| リンクスティップ | 耳の先に生える飾り毛(メインクーンなど) |

## しくみ

### しま模様があるか、ないか

1本の毛を見ると、黒っぽい帯と明るい帯が交互になっていることがある。これを「アグーチ」の毛という。アグーチの毛がある猫は、しま模様が見える。ないと全身が同じ色の単色(黒猫など)になる。ただし茶トラは、遺伝子のしくみ上、単色でもしまがうっすら残りやすい。

### しまの形を決める遺伝子

細いしまのマッカレルと、太い渦巻きのクラシックの違いは、Taqpep(現在の名前はLVRN)という遺伝子で決まることがわかっている。体にしまが出ないティックドは、DKK4という別の遺伝子によるもので、ほかのしま模様を上からおおい隠す。スポッテッドは、しまが途切れて斑点になったものと考えられている。

### 色の濃さ・薄さ

黒を薄める遺伝子がはたらくと、黒はブルー(グレー)、チョコレートはライラック、茶(レッド)はクリームになる。ロシアンブルーやブリティッシュショートヘアのグレーは、この「薄まった黒」だ。毛の根元の色を抑える遺伝子がはたらくと、サバトラやアメショのような白っぽい銀色(シルバー)になる。

### 体の先だけ色が濃い「ポイント」

シャムやラグドールの耳・顔・足・しっぽが濃いのは、色をつくる酵素が温度の影響を受けるため。体温の低い体の先ほど色が濃くなる。同じしくみでも遺伝子のタイプが違うと、色の差がゆるやかな「セピア」(バーミーズ)になり、ポイントとセピアの中間が「ミンク」(トンキニーズ)だ。ラグドールの子猫が白っぽく生まれ、毛色が出そろうまで2歳ごろまでかかるのも、色がゆっくり濃くなるからだ。

### 白の入り方

白い毛の入り方は、KITという遺伝子のタイプで変わる。全身真っ白、白とのブチ(バイカラー、ハチワレ)、バーマンの白い手袋のような模様は、どれもこの遺伝子が関わっている。

### 三毛とサビ

茶色を出す遺伝子はX染色体にあるため、黒と茶がまざる三毛やサビは、基本的にメスになる。オスの三毛がとても珍しい理由は<a href="/columns/calico-male/">オスの三毛猫はなぜ珍しい?</a>にくわしい。

## 猫種の呼び名

- ラグドール:<strong>カラーポイント</strong>(白なし)、<strong>ミテッド</strong>(白い前足とあご)、<strong>バイカラー</strong>(顔に白い逆V字)、<strong>バン</strong>(白が多い)の4つの模様がある(CFA)。
- ベンガル:模様は<strong>スポッテッド</strong>と<strong>マーブル</strong>。斑点の中が明るく抜けた<strong>ロゼット</strong>は、形によってアローヘッド(矢じり)・パウプリント(肉球)・ドーナツ・クラスター(房)などと呼ばれる。毛色はブラウン、白っぽい<strong>スノー</strong>(シール・リンクスポイント、シール・ミンク、シール・セピア)、シルバーなど(TICA)。毛先が輝く<strong>グリッター</strong>もある。
- メインクーン・ノルウェージャンフォレストキャット・サイベリアン:耳の先の飾り毛を<strong>リンクスティップ</strong>、耳の内側の飾り毛を<strong>イヤータフト</strong>と呼ぶ。

くわしくは<a href="/breeds/">猫種図鑑</a>の各ページの「毛色と模様の呼び名」に書いている。

## よくある誤解

- <strong>毛色で性格が決まる?</strong> 「茶トラは甘えん坊」のような話はよく聞くが、毛色と性格の関係ははっきりしていない。性格は一匹ずつ違う。
- <strong>子猫の模様は大人になっても同じ?</strong> 色や模様がはっきりするまで時間がかかる猫種がある。ラグドールは2歳ごろ、ベンガルも1年以上かけて模様がくっきりしていくといわれる。

## 飼い主向けメモ

- 呼び名は登録団体(CFA・TICAなど)や国によって少しずつ違う。同じ模様に別の名前が付いていることもある。
- ポイントの猫は、寒い季節や体の冷えやすい場所で色が濃くなることがある。
- 毛色や模様は見分けの手がかりになる。迷子のときにそなえて、全身や模様のはっきりした写真を撮っておこう。

キジトラもポイントもロゼットも、猫好きは結局ぜんぶの模様が好きだ。
