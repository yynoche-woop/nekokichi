「猫と暮らしたい」と思った瞬間から、人はもう半分ネコキチだ。スマホの待ち受けが猫になり、道ばたの猫に会釈するようになる。ここからが大事で、猫を迎える準備は、猫が家に来る前にやっておくほうが圧倒的にラクだ。来てしまったら、かわいさで何も手につかなくなるので。

## 結論

猫を迎える前にやっておきたいことは、大きく4つ。

1. <strong>暮らしの確認</strong>:住まいが猫を飼えるか、家族全員が賛成か、十数年先まで一緒に暮らせるか
2. <strong>用意するもの</strong>:トイレ、爪とぎ、寝床、食器、キャリーなど
3. <strong>部屋の安全対策</strong>:脱走、誤飲、危ない植物やコードの対策
4. <strong>最初の動物病院</strong>:迎えたらすぐ行ける病院を決めておく

そして、どこで猫と出会うか。環境省のガイドラインでも、<strong>保健所などの保護施設や保護ボランティアから迎えることも考えてほしい</strong>と書かれている。

## くわしく

### まず「暮らせるかどうか」を確認する

環境省の「住宅密集地における犬猫の適正飼養ガイドライン」は、飼う前に考えるポイントとして、次のようなことを挙げている。

- 住まいがペット可か。賃貸や集合住宅なら規約や許可を確認する。転居や転勤の予定はないか
- 家族全員が飼うことに賛成しているか
- 家族に動物アレルギーの人はいないか(心配なら先に医師に相談)
- 毎日の世話の時間と、体力はあるか
- ごはん、用品、ワクチンや健康診断、病気やけがの治療など、一生を通してお金がかかることを考えたか
- 猫は十数年以上生きる。進学・就職・結婚・出産など、人の側の変化があっても飼い続けられるか
- 万一飼えなくなったとき、代わりに世話をしてくれる人のあてはあるか

どれも耳の痛い項目だが、猫にとっては「一生そこで暮らす家」を決める話だ。ここを先に済ませておくと、あとで迷わない。

### 用意するもの

環境省のガイドラインでは、猫は室内で飼うのが基本とされ、上下運動できる場所や落ち着ける場所を用意すれば室内で暮らせるとしている。用意するものの例はこうだ。

| もの | ポイント |
|---|---|
| トイレと猫砂 | 汚れたトイレは嫌われる。International Cat Careは「猫の数+1個」を勧めている |
| 爪とぎ | 爪とぎは習性なので、やめさせるより専用の場所を用意する。縦型と横型で好みが分かれる |
| 寝床・隠れ場所 | 体がすっぽり入る箱やハウス。段ボール箱にタオルでもいい |
| 食器と水入れ | ヒゲが当たりにくい、浅くて広めの器。水はごはんから離れた場所にも |
| キャリー | 病院への移動用。ふだんから部屋に置いて寝床として慣らしておくと、通院のストレスが減る |
| キャットタワー・棚 | 高いところで落ち着く猫が多い。上下運動にもなる |
| 迷子札・首輪 | 万一の脱走に備えて連絡先を |
| ごはん | 迎える前に、それまで食べていたものを聞いておく。量は<a href="/tools/food/">ごはんの量計算</a>で目安が出せる |

International Cat Careは、ごはん・水・トイレ・休む場所を<strong>家の中でそれぞれ離して置く</strong>ことを勧めている。トイレのすぐ横でごはん、は猫もイヤだ。人間もイヤだ。

### 部屋の安全対策

- <strong>脱走対策</strong>:玄関や窓、ベランダの出入り。環境省のガイドラインでも、ドアのすき間からの脱走や、雷・花火でパニックになって飛び出すことへの注意が書かれている
- <strong>誤飲対策</strong>:ひも、輪ゴム、ヘアゴム、薬、小さなおもちゃは出しっぱなしにしない
- <strong>危ない植物・食べ物</strong>:ユリなどは置かない。くわしくは<a href="/columns/toxic-foods/">猫が食べてはいけないもの一覧</a>
- <strong>コードと家電</strong>:かじりやすい電源コードはカバーをつけるか隠す。洗濯機や冷蔵庫に入りこむことも
- <strong>室温</strong>:夏と冬の目安は<a href="/columns/room-temp/">猫の室温の目安</a>で

猫は箱と狭い場所が大好きなので、家じゅうのすき間が「猫の居場所」になりうる。人間の目線ではなく、床から30cmの目線で一度部屋を見回してみるといい。箱がなぜあんなに好きかは<a href="/columns/boxes/">猫と箱の記事</a>で。

### 最初の動物病院

迎える前に、家から通いやすい動物病院を探しておく。猫が来たら、なるべく早めに健康診断を受けておきたい。オリーブペットクリニックの解説では、便の検査で寄生虫がいないか、ウイルス検査(猫エイズ・猫白血病)などを確認することが紹介されている。ウイルス検査は感染してから日が浅いと正しく出ないことがあるため、時期をずらして検査することもある。いつ何を受けるかは病院で相談しよう。

<strong>先住猫がいる家</strong>では、新しい猫の健康状態がわかるまで別の部屋で過ごさせることが勧められている。同クリニックは、できれば1か月ほど隔離を、としている。いきなり対面させるのは、猫どうしの相性の面でもおすすめしない。

ワクチンや不妊・去勢手術のタイミングも、この最初の受診で聞いておくといい。環境省のガイドラインでは、不妊去勢手術は早めに、最初の発情の前に行うのが有効とされている。

### 保護猫の譲渡という選択肢

全国の自治体の動物愛護センターなどでは、新しい家族を探している猫がいる。環境省の「収容動物検索情報サイト」には、各地の施設の譲渡会の情報や連絡先がまとめられていて、譲渡の条件は施設ごとに違うので問い合わせてほしい、とされている。

例として、東京都動物愛護相談センターでは、事前講習会を受けたうえで、家族全員の同意、動物アレルギーがないこと、不妊去勢手術を確実に行えること、集合住宅なら飼育許可があること、などの条件を確認して譲渡している。条件が細かいのは、猫が「二度と迷子にならない家」を探すためだ。

環境省のガイドラインは、子猫は病気になりやすく世話も細かいのに対して、<strong>成猫は大きさや性格がわかっていて、世話が比較的ラク</strong>という利点にも触れている。はじめての猫に、落ち着いた大人の猫はかなりいい相棒になる。

### マイクロチップの手続き

2022年6月から、販売される犬猫にはマイクロチップの装着と登録が義務になった。東京都の案内によると、マイクロチップが入った猫を迎えたら、<strong>30日以内に飼い主情報の変更登録</strong>が必要になる。すでに飼っている猫への装着は努力義務とされている。譲渡元や病院で、チップの有無と手続きを確認しておこう。

## 病院に相談する目安

新しい環境に来たばかりの猫は、緊張してしばらく隠れていたり、食べる量が減ったりすることがある。ただ、次のようなときは早めに相談してほしい。

- 丸一日以上ほとんど食べない・飲まない
- 吐く、下痢が続く
- くしゃみ・鼻水・目やにがひどい
- おしっこが出ていない様子がある(すぐ受診。<a href="/columns/emergency-signs/">すぐ動物病院へ行くべき猫の症状</a>も参照)

ペットショップの子も、ブリーダーの子も、保護施設の子も、道で出会った子も、家に来たらみんな「うちの子」。そして気づけば、全部の猫がかわいく見えるようになっている。ようこそ、こちら側へ。
