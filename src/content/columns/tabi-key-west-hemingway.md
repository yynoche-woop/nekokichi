アメリカ本土の最南端、フロリダ半島から島づたいに橋が続いた先にキーウェストがある。作家アーネスト・ヘミングウェイが1930年代に暮らした家は今は博物館になっていて、庭にも屋内にも猫がいる。しかも、その多くは前足の指が6本ある。

## 基本データ

| 項目 | 内容 |
|---|---|
| 場所 | 907 Whitehead Street, Key West, Florida(アメリカ) |
| 猫の数 | 60匹近く(博物館の公式サイト) |
| 猫の特徴 | 全頭が多指症の遺伝子を持ち、約半数は指が多い |
| 開館 | 毎日 9:00〜17:00、年中無休 |
| 入場料 | 大人19ドル、6〜12歳7ドル、5歳以下無料(現地の正門で購入) |
| 東京から | 直行便なし。アメリカ本土で乗り継ぎ |

## 6本指の猫の由来

博物館によると、ヘミングウェイは船長から6本指の白い猫「スノーホワイト」を贈られた。今いる猫の多くは、その子孫だという。

指が多い猫は「多指症」と呼ばれる。猫では前足に出ることが多く、遺伝子の一つが顕性で伝わるため、親から子へ受け継がれやすい。

猫たちには有名人の名前を付けるという、ヘミングウェイの習慣が今も続いている。獣医師が定期的に診察し、ワクチンやノミ・寄生虫の予防もしている。

## 見どころ

### ガイドツアー
入場するとガイドツアー(20〜30分)に参加できる。9:15から15分おきに出発し、家の歴史と猫の話を聞ける。<strong>日本語の翻訳台本</strong>が用意されているので、英語が不安でも楽しめる。

### 家と庭
スペイン植民地風の屋敷と、熱帯の植物が茂る庭。その敷地のあちこちで、猫が当たり前のように過ごしている。

## 東京からの行き方

| 区間 | 目安 |
|---|---|
| 羽田→アメリカ本土 | ダラス(約12時間45分)、ヒューストン(約13時間20分)、アトランタ(約13時間30分)など |
| 本土→キーウェスト空港 | ダラス・マイアミ・ヒューストン・アトランタなどから直行便(季節運航の路線あり) |
| マイアミから車 | 約110マイル(約180km)、約4時間 |

2026年10月時点で、東京からマイアミ・キーウェストへの直行便はない。マイアミから海の上の橋を走るドライブも、それ自体が名物になっている。

## 訪ねるときのマナー

- 猫は博物館の家族。触ったりエサをあげたりのルールは公式サイトに書かれていないので、スタッフの案内に従う
- カードやスマホ決済には3%の手数料がかかる
- <strong>6月1日〜11月30日はハリケーンシーズン</strong>。特に8月中旬〜10月中旬は天気予報をよく確認する

## 編集部のひとこと

指が多いからといって特別に強いわけでも、弱いわけでもない。どの猫も猫。それでも、ふっくらした「ミトン」のような前足は、一度見ると忘れられない。
