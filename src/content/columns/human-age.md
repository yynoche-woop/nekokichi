「うちの子、人間でいうと何歳?」。誕生日のたびに誰もが一度は計算する。そして「えっ、もう私より年上…?」と軽くショックを受けるまでがセットだ。数字のショックはさておき、年齢の目安を知っておくと、健康診断やごはんを見直すタイミングがつかみやすくなる。

計算がめんどうなら、サイト内の<a href="/tools/age/">猫の年齢換算</a>に数字を入れるだけでいい。

## 結論

いちばんよく使われている換算の目安はこれだ。

- <strong>猫の1歳 = 人の約15歳</strong>
- <strong>猫の2歳 = 人の約24歳</strong>
- <strong>そこから先は、猫の1年 = 人の約4年</strong>

式にすると、2歳以上なら「24 +(猫の年齢 − 2)× 4」。International Cat Care(猫の福祉団体)の換算表もこの考え方で、国内の保険会社の獣医師監修記事でも同じ目安が使われている。

ただし、これは「そのくらいの成長段階」というたとえで、医学的にぴったり対応するわけではない。健康管理の区切りとしては、獣医師の団体が決めている<strong>ライフステージ</strong>のほうが役に立つ。

## くわしく

### 最初の2年で一気に大人になる

換算表をそのまま読むと、子猫は生まれてから1年で、人間でいう15歳あたりまでを駆け抜ける。赤ちゃんから中学生まで、ぜんぶ1年で。2年目でさらに成熟して、24歳くらいの「若い大人」になる。そこから先は、人間よりずっとゆっくり、1年に4歳ぶんずつ年をとっていく。

子猫期(1歳未満)の換算は資料によって数字が少しずつ違う。月齢のうちは「人間の年齢」より、体重がちゃんと増えているか、ワクチンや健康診断の予定はどうか、を見るほうが大事だ。

### AAHA/AAFPのライフステージ

アメリカ動物病院協会(AAHA)とアメリカ猫臨床医協会(AAFP)は、2021年に猫のライフステージのガイドラインを出している。そこでは猫の一生を次のように分けている。

- <strong>子猫(キトン)</strong>:0〜1歳
- <strong>若い成猫(ヤングアダルト)</strong>:1〜6歳
- <strong>成熟した成猫(マチュアアダルト)</strong>:7〜10歳
- <strong>シニア</strong>:10歳以上
- <strong>終末期(エンドオブライフ)</strong>:年齢に関係なく

以前の版では6つに分けていたが、2021年版で整理された。「終末期」が年齢で決まっていないのがポイントで、若くても重い病気なら終末期のケアが必要になる、という考え方だ。

なお、International Cat Careの換算表では、ジュニア、アダルト、マチュア、シニア、スーパーシニアのように別の区切り方をしている。団体によって呼び方や区切りは少し違うので、「7歳くらいから中年、10歳を過ぎたらシニア」くらいに覚えておけば実用上は十分だ。

### 猫はどのくらい生きる?

International Cat Careは、猫の平均寿命をおよそ12〜14歳、10代後半から20代まで生きる猫も珍しくないとしている。日本の調査では、アイペット損保の記事によると、ペットフード協会が2025年に公表した猫の平均寿命は16歳ほど。家の外に出ない猫のほうが長い傾向も出ている。換算すると、16歳の猫は人間の80歳くらいにあたる。

ちなみに、猫種や体の大きさで換算を変えるべきかどうかは、はっきりした根拠を編集部は見つけられなかった。長毛も短毛も雑種も、今のところ同じ物差しでいい。どの子も同じ速さで年をとって、同じだけ長生きしてほしい。それだけだ。

## 猫の年齢の早見表

2歳以上は「24 +(年齢 − 2)× 4」で計算した目安。ライフステージはAAHA/AAFPの区分。

| 猫の年齢 | 人間でいうと(目安) | ライフステージ |
|---|---|---|
| 6か月 | 約10歳 | 子猫 |
| 1歳 | 約15歳 | 若い成猫の入り口 |
| 2歳 | 約24歳 | 若い成猫 |
| 3歳 | 約28歳 | 若い成猫 |
| 5歳 | 約36歳 | 若い成猫 |
| 7歳 | 約44歳 | 成熟した成猫 |
| 9歳 | 約52歳 | 成熟した成猫 |
| 10歳 | 約56歳 | 成熟した成猫〜シニア |
| 12歳 | 約64歳 | シニア |
| 15歳 | 約76歳 | シニア |
| 18歳 | 約88歳 | シニア |
| 20歳 | 約96歳 | シニア |

6か月の値はInternational Cat Careの表にもとづく。月齢の換算は資料で幅があり、1歳未満のくわしい目安は<a href="/tools/age/">猫の年齢換算</a>でも確認できる。

### 年齢ごとに見直したいこと

- <strong>1歳前後</strong>:子猫用から成猫用のごはんへの切り替えを、かかりつけ医と相談。体型は<a href="/tools/bcs/">体型チェック</a>で
- <strong>7歳前後</strong>:人でいえば40代。健康診断の内容や頻度を見直すタイミング。アイペット損保の記事では、7歳までは年1回、それ以降は年2回の健康診断が勧められている
- <strong>10歳以降</strong>:シニア。段差をなくす、トイレのふちを低くするなど、暮らしやすさの見直しも
- ごはんの量は年齢と体重で変わる。<a href="/tools/food/">ごはんの量計算</a>で目安を出せる

## 病院に相談する目安

年をとること自体は病気ではない。ただ、SBIペットの記事でも触れられているように、<strong>老化のサインと病気の初期のサインは似ている</strong>ことがある。「年のせいかな」で済ませず、次のような変化が続くときは相談してほしい。

- 水を飲む量やおしっこの量が明らかに増えた
- 食べているのに体重が減ってきた
- 寝てばかりで、高いところに上らなくなった
- 毛づくろいをしなくなり、毛並みがぼさぼさになった
- 急に鳴く回数が増えた、夜中に鳴く

どれも「いつもと比べてどうか」が大事なので、元気なうちに体重と様子を記録しておくと、変化に気づきやすい。

猫が人間の年齢を追い越していくのは寂しいけれど、何歳になっても猫は猫。16歳でも20歳でも、かわいさは全年齢対象だ。
