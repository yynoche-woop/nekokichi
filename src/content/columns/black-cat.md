<strong>黒猫</strong>は、全身が黒い毛の猫のこと。猫種の名前ではなく毛色の名前で、雑種にもいろいろな猫種にもいる。「黒猫が前を横切ると不吉」という言い伝えには根拠がなく、国によっては同じ出来事が幸運のしるしとされる。日本でも、黒猫は長く「福猫」だった。

## 基本データ

| 項目 | 内容 |
|---|---|
| 黒くなるしくみ | A遺伝子(アグーチ遺伝子)が「aa」の組み合わせになると、毛が黒くなる |
| 見た目のバリエーション | 毛が赤みがかって見える子、胸に白い毛(エンジェルマーク)がある子も |
| 日本での歴史 | 平安時代から飼われた記録。宇多天皇の黒猫が知られる |
| 日本での言い伝え | 魔除け・幸運・商売繁盛の「福猫」 |
| 不吉のイメージ | 明治の終わりごろ以降に海外から入ったと考えられている |

## しくみ(毛色の遺伝)

獣医師の解説によると、毛の色を決める遺伝子のひとつがA遺伝子(アグーチ遺伝子)で、これが「aa」の組み合わせになると、毛が一本ずつ黒一色になる。黒猫はほかの毛色の遺伝子も持っていて、それが表に出にくいだけ、ともされる。ねこのきもちの解説では、毛が赤みがかって見える子や、胸にちょこっと白い毛(エンジェルマーク)が入る子もいると紹介されている。

## 言い伝えの歴史

### 国が変わると、意味が真逆になる

イギリスの猫保護団体 Cats Protection のまとめによると、黒猫の言い伝えは国や地域でまるで違う。

| 地域 | 黒猫の言い伝え |
|---|---|
| イギリス | 前を横切られるのは幸運 |
| スコットランド | 見知らぬ黒猫が戸口に来ると、家が栄える |
| ヨークシャー(英) | 飼うのは幸運、道で会うのは不運 |
| イタリア | 黒猫のくしゃみは幸運 |
| 日本 | 前を横切るのは幸運、とする言い伝えがある |
| アメリカ、ベルギー、スペイン | とても不吉とされる |

同じ団体の解説では、黒猫は古代エジプトで崇められ、ローマでも愛されていたが、17世紀には猫が魔女と結びつけられるようになった。「不吉」のイメージは、その流れの中で育ったものだ。同じ出来事の意味を変えているのは、見る側の文化である。

### 日本の黒猫は「福猫」だった

ねこのきもちの解説によると、日本では平安時代から黒猫が飼われていて、宇多天皇が黒猫を飼っていたことが日記『寛平御記』に残る。黒猫は「夜でも目が見える」ことから、魔除けや幸運、商売繁盛の象徴とされた。江戸時代には「黒猫を飼うと結核が治る」という俗信まで広まった(医学的な根拠はない)。福猫としての見方は、明治40年ごろまで記録に残っている。

今の「黒猫は不吉」というイメージは、<strong>明治の終わりごろ以降に海外から入ってきたもの</strong>と考えられている。夏目漱石の『吾輩は猫である』のモデルも黒猫で、漱石夫妻に福猫としてかわいがられていたそうだ。

## 研究とデータ(保護猫の譲渡)

2026年にアメリカで発表された研究では、1,004人に保護猫の写真40枚(黒・白・茶トラ・キジトラ各10枚)を見せて評価してもらった。黒猫は、ほかの色より「迎えたい」の評価が低く、怖がっている・怒っているように受け取られやすかった。見る人も、黒猫の表情を読み取る自信が低かった。一方で、迷信を信じているかどうかと評価の低さには関係が見られなかった。研究者は、写真の明るさやコントラスト、動画の活用などを提案している。

ただし、黒猫がいつも不利というわけでもない。2019年のオーストラリア・シドニーの保護施設の調査では、譲渡までの日数は<strong>白猫のほうが黒猫より長かった</strong>(約28%長い)。地域や施設によって事情は変わる。

## 猫種・年齢・性別による違い

- <strong>猫種</strong>:黒は多くの猫種に見られる毛色。上のシドニーの調査では、純血種か雑種かで譲渡までの日数に差はなかった
- <strong>年齢</strong>:同じ調査では、猫の年齢で譲渡までの日数が変わった(12週未満の子猫は中央値39日、7〜10歳は18日、2歳超は30日)
- <strong>性別</strong>:同じ調査では、性別による差はなかった
- 2026年の研究で差が出たのは、評価する<strong>人</strong>の年齢や性別のほう。猫自身の年齢・性別は分析されていない

## よくある誤解

- <strong>「黒猫が前を横切ると不吉」</strong>:根拠はない。イギリスや日本では幸運のしるしとする言い伝えもある
- <strong>「黒猫は迷信のせいで迎えられにくい」</strong>:2026年の研究では、迷信を信じるかどうかと評価には関係がなかった。写真で表情が伝わりにくいことのほうが影響していそうだ

## 飼い主向けメモ

- 黒猫を撮るときは、明るい窓辺や、白やベージュなど明るい背景を選ぶ。少し明るめに撮ると表情が写りやすい
- 目にピントを合わせると、黒い顔でも表情が伝わりやすい。保護猫の里親募集の写真でも役立つ
- 毛のつやが急に変わった、フケが増えた、というときは、黒猫に限らず体調のサインのことがある。気になったら動物病院に相談する
- 黒猫を迎えたい人は、保護団体や自治体の譲渡も選択肢に。会える機会があれば、実際に会ってみるのがおすすめ
